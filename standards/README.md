# Директория для темы и системного промпта

Сюда помещается файл assignment.txt
с примерно таким содержанием:

Тема: Совершенствование системы защиты информации распределенной организации за счет внедрения модели изолированных сессий рабочих станций с гарантированным восстановлением исходной конфигурации на примере ...

Требования к работе:
- Объем: 10-15 страниц
- Структура: введение, теоретическая часть, практическая реализация, заключение
- Использовать актуальные источники (2018-2024 гг.)
- Рассмотреть современные угрозы для распределенных организаций
- Проанализировать существующие модели изоляции сессий
- Предложить архитектуру системы с гарантированным восстановлением
- Разработать план внедрения для ООО "Академия ТОП"
- Оценить экономическую эффективность решения

Технические требования:
- Рассмотреть технологии: Docker, VMware, Citrix, терминальные серверы
- Проанализировать методы гарантированного восстановления (snapshots, образы системы)
- Учесть требования ФСТЭК России и ФЗ-152
- Предложить механизмы аутентификации и авторизации

Дополнительные указания:
- Соблюдать строгий академический стиль
- Использовать профессиональную терминологию ИБ
- Приводить конкретные технические решения
- Дать сравнительный анализ с существующими подходами
- Предложить метрики оценки эффективности

Формат вывода:
- Markdown с четкой структурой заголовков
- Таблицы для сравнительного анализа
- Блоки кода для технических решений
- Список литературы в конце
