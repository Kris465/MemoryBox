# Настройка для 2 мониторов и автозапуска

## 2 Монитора

Lively Wallpaper поддерживает несколько мониторов. Есть 2 варианта:

### Вариант 1: Одинаковые обои на обоих мониторах
1. Открой Lively Wallpaper
2. Нажми меню → **Настройки** (Settings)
3. Вкладка **Обои** (Wallpaper)
4. Включи **«Разрешить несколько обоев»** (Allow multiple wallpapers)
5. Перетащи обои на второй монитор

### Вариант 2: Разные обои на каждом мониторе
1. Создай копию папки:
   ```
   D:\repos\wallpaper\live_wallpaper_monitor2\
   ```
2. В `script.js` измени скорость или файлы для разнообразия
3. В Lively добавь обе папки как разные обои
4. Назначь каждую на свой монитор

## Автозапуск при старте Windows

Lively Wallpaper должен запускаться автоматически. Проверь настройки:

### Способ 1: Через настройки Lively (рекомендуется)
1. Открой Lively Wallpaper
2. Нажми меню → **Настройки**
3. Вкладка **Система** (System)
4. Включи **«Запускать при входе в систему»** (Start with Windows)
5. Включи **«Запускать в свёрнутом виде»** (опционально)

### Способ 2: Через автозагрузку Windows
1. Нажми `Win + R`
2. Введи: `shell:startup`
3. Нажми Enter (откроется папка автозагрузки)
4. Создай ярлык для Lively:
   - ПКМ → Создать → Ярлык
   - Путь: `"C:\Program Files\lively wallpaper\Lively.exe"` (или где у тебя установлен)
   - Готово

### Способ 3: Через планировщик заданий
1. Открой **Планировщик заданий** (Task Scheduler)
2. Создай задачу:
   - Триггер: **При входе в систему**
   - Действие: Запустить `Lively.exe`
   - Галочка: **Запускать с наивысшими правами**

---

## Проверка автозапуска

1. Открой **Диспетчер задач** (`Ctrl + Shift + Esc`)
2. Вкладка **Автозагрузка**
3. Найди **Lively Wallpaper**
4. Статус должен быть **«Включено»**

---

## Если обои не печатают при запуске

1. Открой консоль браузера (F12) в Lively:
   - меню → **Разработчик** (Developer) → **Отладка обоев**
2. Проверь консоль на ошибки
3. Убедись, что `data.js` существует и содержит `CODE_FILES`

### Быстрая проверка data.js:
Открой `D:\repos\wallpaper\live_wallpaper\data.js` и проверь, что в начале файла есть:
```javascript
const CODE_FILES = [
    {
        path: `...`,
        ...
    }
];
```

Если файл пустой — запусти:
```bash
python D:\repos\wallpaper\live_wallpaper\generate_data.py
```
