# Живые обои для рабочего стола

Терминальные обои с имитацией vim/nano. Код выводится посимвольно, как будто вы набираете его в терминале.

## Быстрый старт

### 1. Установка в Lively Wallpaper
1. Откройте **Lively Wallpaper**
2. Нажмите **«+»** (Add Wallpaper)
3. Перетащите папку `live_wallpaper` в окно Lively ИЛИ
   - Выберите «Веб-страница» → «Обзор»
   - Укажите путь: `D:\repos\wallpaper\live_wallpaper\index.html`
4. Готово!

### 2. Для 2 мониторов и автозапуска
См. **[SETUP.md](SETUP.md)** — подробная инструкция.

## Обновление файлов

Если вы добавили новые файлы в репозитории, обновите `data.js`:

```bash
python D:\repos\wallpaper\live_wallpaper\generate_data.py
```

После этого в Lively обои автоматически подхватят изменения.

## Настройка

Откройте `script.js` и измените `CONFIG`:

```javascript
const CONFIG = {
    TYPING_SPEED: 15,        // Скорость написания (мс на символ)
    FILE_CHANGE_DELAY: 3000, // Пауза после завершения (мс)
    SHOW_LINE_NUMBERS: true, // Номера строк слева
    MAX_CHARS: 5000,         // Макс. длина файла для показа
};
```

### Рекомендуемые значения:

| Параметр | Быстро | Нормально | Медленно |
|----------|--------|-----------|----------|
| `TYPING_SPEED` | 5-10 | 15-25 | 30-50 |
| `FILE_CHANGE_DELAY` | 1000 | 3000 | 5000 |

## Как работает

1. `generate_data.py` сканирует `D:\repos` и собирает все файлы кода
2. Создаётся `data.js` с содержимым файлов
3. `script.js` выбирает случайный файл и печатает его посимвольно
4. После завершения ждёт 3 секунды и показывает следующий файл

## Стиль

- Тёмная тема в стиле GitHub Dark / VS Code
- Моноширинный шрифт Consolas
- Мигающий синий курсор
- Статус-бар как в vim:

  - Справа: прогресс, часы

## Если не работает

### Обои не печатают при запуске
1. Открой Lively → Разработчик → Отладка обоев
2. Нажми F12 → консоль
3. Проверь ошибки
4. Убедись, что `data.js` содержит `CODE_FILES`

### Файлы не обновляются
Запусти заново:
```bash
python D:\repos\wallpaper\live_wallpaper\generate_data.py
```

### Тормозит
Увеличь `TYPING_SPEED` или уменьши `MAX_CHARS` в `script.js`.
